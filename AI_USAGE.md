# AI Usage Disclosure

AI tooling was used to review the assignment, design the initial architecture for the otherwise empty workspace, and assist with implementing calculation history, keyboard shortcuts, exponentiation, square root, responsive styling, documentation, and associated tests.

The implementation prompt requested a production-quality React/TypeScript and Go calculator with server-side arithmetic, structured validation errors, defensive `localStorage` history capped at 50 entries, shared mouse/keyboard actions, accessible responsive UI, comprehensive tests, and design-decision documentation. Generated code and recommendations were exercised through the available automated checks and manually reviewed and adapted before inclusion.

AI tooling also assisted with the reproducible coverage configuration/report, Makefile commands, and the multi-stage Docker packaging that serves the compiled frontend and API from one Go process.

AI tooling later assisted with extending the lightweight typography, adding reduced-motion-safe display feedback, and testing visible mathematical and syntax error states.

AI tooling also assisted with the collapsible scientific calculator section, typed unary-operation API integration, domain validation, and scientific-operation tests.
